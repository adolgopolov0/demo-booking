# Функционал и тест-кейсы контроллера

Методы `index`, `store`, `destroy`, `today` в `app/Http/Controllers/BookingController.php`. Маршруты в `routes/api.php` закрыты `auth:sanctum`. Сидер создаёт офисы, комнаты и пользователей, броней не создаёт.

## Данные

- Москва, `Europe/Moscow`: Арбат (1), Тверская (2), Остоженка (3).
- Новосибирск, `Asia/Novosibirsk`: Обь (4), Академгородок (5).
- Анна, id 1, токен `anna-token`. Борис, id 2, токен `boris-token`.
- Запросы идут с `Authorization: Bearer <токен>` и `Accept: application/json`.

## Что делают методы

- `GET /api/bookings` возвращает брони текущего пользователя, сортировка `starts_at` по убыванию, страница по 20.
- `POST /api/bookings` создаёт бронь. Пример из README: комната 1, `user_id` 1, «Планёрка», `2026-11-02T10:00:00+03:00`–`11:00:00+03:00`. Пересечение той же комнаты отвечает 409 «Комната занята». Час начала вне 9–20 отвечает 422 «Нерабочее время». Успех пишется в `storage/logs/bookings.log`.
- `DELETE /api/bookings/{id}` удаляет бронь по id и отвечает 204. Нет id — 404.
- `GET /api/rooms/{room}/bookings/today` возвращает брони комнаты на сегодня, у каждой поля `time` и `author`. Нет комнаты — 404.

## auth

1. Запрос без токена с `Accept: application/json` даёт 401.
2. Запрос без токена и без `Accept` даёт 500.

## index

1. Пользователь один (Анна, `anna-token`) видит свои брони и не видит брони Бориса.
2. Пользователь два (Борис, `boris-token`) видит свои брони и не видит брони Анны.
3. У Анны нет броней, список пустой.
4. Несколько броней Анны идут по `starts_at` убыванию, на странице 20 записей.

## store

1. Пользователь один (Анна) создаёт бронь на Арбат и присылает своё время со смещением `2026-11-02T10:00:00+03:00`–`11:00:00+03:00`, заголовок «Планёрка». В БД время бронирования пишется по часовому поясу офиса Москвы (`Europe/Moscow`). В `storage/logs/bookings.log` появляется запись.
2. Пользователь два (Борис) создаёт бронь на свободное время, Тверская `10:00–11:00+03:00`, успех.
3. Пользователь два (Борис) занимает уже занятое время Арбата `10:00–11:00+03:00` и получает 409 «Комната занята».
4. Пользователь один (Анна) создаёт бронь на Обь и присылает время со смещением `2026-11-02T10:00:00+07:00`–`11:00:00+07:00`. В БД время пишется по часовому поясу офиса Новосибирска (`Asia/Novosibirsk`).
5. Пользователь один (Анна) присылает начало `08:00+03:00` на Арбат и получает 422 «Нерабочее время».
6. Пользователь один (Анна) присылает начало `20:00+03:00` на Арбат и получает 422 «Нерабочее время».

## destroy

1. Пользователь один (Анна) отменяет свою бронь и получает 204, затем эта бронь не видна в её `index`.
2. Пользователь два (Борис) отменяет свою бронь и получает 204, затем эта бронь не видна в его `index`.
3. Удаление отсутствующего id возвращает 404.

## today

1. На Арбате за сегодня видны брони этого дня, у каждой время и имя автора.
2. Бронь Арбата за вчера в список сегодня не входит.
3. Обь не показывает брони Арбата.
4. Запрос комнаты, которой нет, возвращает 404.
